# Visits workbench

The Console `/visits` route uses a parameterized, company-scoped join from Service Visit to Service Job. It shows schedule, customer, Job, team/technician, equipment count and status, with direct Job drill-down. Filters accepted by the API are status, Job and date range; the result is bounded to 500.

Calendar and richer result/SLA columns remain presentation enhancements, not alternate lifecycle state.
